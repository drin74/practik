## Возможности
- добавление, изменение, просмотр и удаление клиентов;
- добавление, изменение, просмотр и удаление автомобилей;
- создание и редактирование заказов, смена статуса;
- поиск заказов по государственному номеру автомобиля;
- отчет по выполненным заказам и сумма стоимости работ;
- проверка обязательных полей и стоимости, обработка ошибок MySQL.

## Запуск
1. Откройте MySQL Workbench и выполните весь файл `database.sql`.
2. Откройте `main.py` и в начале файла поменяйте `DB_CONFIG`:
   - `user` — имя пользователя MySQL;
   - `password` — ваш пароль MySQL.
3. В терминале в папке проекта выполните:
   `python -m pip install -r requirements.txt`
4. Запустите:
   `python main.py`

## Как пользоваться
1. На вкладке «Клиенты» добавьте клиента.
2. На вкладке «Автомобили» укажите ID клиента из первой вкладки, госномер, марку и модель.
3. На вкладке «Заказы» укажите ID автомобиля из вкладки «Автомобили», работу, стоимость и статус.
4. Чтобы изменить запись, сначала выделите её в таблице, затем введите новые данные в поля сверху и нажмите «Изменить выбранного».
5. Кнопка «Отчет выполненных» показывает только заказы со статусом «Выполнен» и считает общую стоимость.

## Примечание
Это учебный пример. Для удаления клиента сначала удалите связанные заказы и автомобили, иначе MySQL не позволит удалить запись из-за связей между таблицами.
